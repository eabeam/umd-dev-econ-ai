# Assignment

The semester assignment (LSMS project, Assignments 1–12) is distributed via ELMS — this folder holds supporting notes only.

Quick pointers for getting started:

- **Assignment 1, step 1** requires a World Bank microdata account and data-use agreement — if you haven't done [setup step 5](../setup/README.md#5-world-bank-microdata-account-start-today), do it now; approval takes days, not minutes.
- Choose a country-year with a **full household module** (not a high-frequency phone survey or a panel-only round).
- Read the questionnaires, enumerator manuals, and Basic Information Document *before* touching the data — the agent can help you digest documentation, but it can't read what you didn't download.
- Keep the [research decisions log](../materials/cleaning_decision_log.md) alongside each assignment's code.
